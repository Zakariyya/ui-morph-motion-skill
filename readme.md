# 搓了个 UI 变形动画 Skill

最近折腾了个专门生成 UI 变形动效的 Skill。

可以把按钮、卡片、开关这些 UI 元素串成一段丝滑的变形动画，鼠标点击、拖动、弹性回弹、音乐卡点都能编排进去。

不只是生成动画视频，还能导出 MP4 和可编辑的 HTML，后面想调整动效也方便。

放一段演示效果，感觉挺适合拿来做产品展示和 UI 设计短片的。

灵感来自 [@twoclipping](https://x.com/twoclipping) 的 [帖子](https://x.com/twoclipping/status/2103273003555402193)
