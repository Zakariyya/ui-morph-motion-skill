# 夸张但清楚的 UI 动效

默认让形变、回弹和交互反应一眼可见。用户明确选择安静、克制的风格时降低强度。保留已确认的状态与声音方案，不为加强动感重新要求用户确认整套分镜。

## 五项动作规则

1. **大幅收缩拉伸**：同一主容器在按钮、圆形、长条、卡片等有明显宽高比差异的轮廓之间连续变形。重要扩张前可以先压缩蓄力，随后快速拉开。不要仅靠微小尺寸变化或内容淡入淡出表现变形；尺寸始终为正，圆角保持合理。
2. **明显回弹**：主形状越过目标，再回到可阅读的稳定状态。用解析弹簧保留速度连续性，避免每次重置造成顿挫。回弹服务于落点，不能持续抖动占满阅读窗口。
3. **镜头推进**：关键展开、点击和状态落点配合推进，状态切换时适度退让；镜头响应比形状更平滑。推进后仍保留安全边距，检查最大过冲时的裁切，不只检查稳定帧。
4. **拖动倾斜**：拖动时主体随方向轻微位移、倾斜，松手带着释放速度回弹。滑块手柄必须直接跟随光标；表现弹性的是容器、轨道或手柄轮廓，不能用手柄落后光标制造“弹性”。tab 和开关两侧可用不同响应形成拉伸，但宽度不得反转。
5. **主体放大**：主 UI 占据画面中心和主要面积，标题、标识及辅助文案退居次要层级。大卡片可从画幅宽度的约 65–82% 试起，圆形和收缩状态允许明显变小；这不是每一帧必须满足的比例。避免大标题挤压主体，或镜头缩放后文字被裁切。

## 参数起点与时间

- 形状可从 `damping=0.55–0.70`、`omega=30–40` 试起；镜头可从 `damping=0.70–0.90`、`omega=20–28` 试起。根据动作间隔与画幅调整，不能机械套用。
- 主体倾斜可从约 2–4 度试起，重要落点的尺寸过冲可从约 10–15% 试起。计算叠加后的真实峰值，不把单个弹簧参数当成安全保证。
- 所有参数先明确使用原始时间还是输出秒数。2 倍速若已用 `seek(2*t)` 映射，不再把弹簧频率重复翻倍。视频节奏与音乐速度独立，视觉更夸张不意味着配乐更快。
- 内容退出和进入独立编排，旧文字先退出，新文字在形状展开过程中及时进入；不要等待整个回弹完全结束才显示内容，造成长时间空壳。入场可短暂模糊、位移和缩放，稳定后文字必须清楚。

## 坐标与确定性

形状、镜头、倾斜、光标和文字都由纯 `seek(t)` 推导，不能依赖上一帧。镜头推进、旋转、平移后，光标必须使用变换后的控件位置；注意浏览器预览容器的额外缩放。可测量实际控件中心再转换到画布坐标，复杂嵌套变换用一致的矩阵转换，不能只沿用变换前坐标。

拖动释放同时保留位置和速度。结尾留出回收时间，使主体尺寸、镜头、倾斜、光标及内容回到循环起点；只对时间取模不能保证接缝连续。

## 交付前复核

查看每拍预览之外，还应密集查看关键过渡（例如每 50–100 ms 一帧），覆盖收缩谷值、拉伸峰值、回弹、镜头推进与拖动释放。检查主体越界、文字叠影、空壳时间、点击命中和整个拖动过程的光标贴合。最终 MP4 连续回放两轮，复核循环接缝和真实音轨。

数值检查只证明边界、坐标和时间一致，不能替代视觉判断或音频试听。技术示例用于验证接口，正式作品要根据已确认分镜落实上述动作。
